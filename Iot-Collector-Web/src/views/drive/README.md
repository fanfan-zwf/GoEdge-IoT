# 驱动配置管理

驱动（Drive）配置页面，管理工业协议驱动连接。

## 📁 文件列表

| 文件 | 说明 |
|------|------|
| `index.vue` | 驱动配置主页面 |

## 🎯 页面功能

- 驱动列表展示
- 新增/编辑驱动配置
- 删除驱动
- 搜索筛选
- 分页
- 导入/导出 Excel

## 📝 支持的驱动类型

| 驱动 | 说明 |
|------|------|
| Modbus_Tcp | Modbus TCP 协议驱动 |
| Siemens_S7 | 西门子 S7 协议驱动（snap7） |
