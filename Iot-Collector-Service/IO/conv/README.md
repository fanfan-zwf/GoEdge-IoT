# conv

工业协议数据采集后的字节解析、类型转换与数值换算工具包。

## 模块职责

| 文件 | 职责 |
|---|---|
| `convertType.go` | 类型编码常量定义（`TYPE_BOOL` ~ `TYPE_STRING`）、类型名称与编码双向映射、`Conv*` 系列类型转换函数 |
| `calculate.go` | 数值换算：比例换算、线性换算、表达式换算、换算+类型转换一体化函数 |
| `byte_util.go` | 字节序处理、位操作、字节切片索引等底层工具函数 |

## Conversion 换算表达式

`Conversion` 字段存储在 `Point_Config` 表的 `Conversion` 列中，用于对采集到的原始值进行数值换算。
字段为空（`""`）时表示不做换算，直接进行类型转换输出。

### 格式规范

表达式使用 **分号 `;`** 分隔各参数，第一个参数为换算模式名称。

### 支持的模式

#### 1. 比例模式

**公式**：`y = k * x + b`

**格式**：`比例;倍率k;偏移量b`

| 参数位置 | 含义 | 类型 | 说明 |
|---|---|---|---|
| 第 1 段 | 模式名称 | 固定值 | 必须为 `比例` |
| 第 2 段 | 倍率 k | float64 | 乘数因子 |
| 第 3 段 | 偏移量 b | float64 | 加法偏移 |

**示例**：

| 表达式 | 含义 | 采集值 100 → 输出 |
|---|---|---|
| `比例;2;0` | y = 2x | 200 |
| `比例;0.1;-5` | y = 0.1x - 5 | 5 |
| `比例;1.5;10` | y = 1.5x + 10 | 160 |

**典型场景**：传感器量程缩放（如 4-20mA 对应 0-100°C，倍率 6.25、偏移 -25）。

#### 2. 线性模式

**公式**：`PV = PvMin + (PvMax - PvMin) * (x - EngMin) / (EngMax - EngMin)`

即将工程值范围线性映射到实际物理值范围。

**格式**：`线性;实际值下限;实际值上限;工程值下限;工程值上限`

| 参数位置 | 含义 | 类型 | 说明 |
|---|---|---|---|
| 第 1 段 | 模式名称 | 固定值 | 必须为 `线性` |
| 第 2 段 | 实际值下限 PvMin | float64 | 物理量下限 |
| 第 3 段 | 实际值上限 PvMax | float64 | 物理量上限 |
| 第 4 段 | 工程值下限 EngMin | float64 | 采集原始值下限 |
| 第 5 段 | 工程值上限 EngMax | float64 | 采集原始值上限 |

**边界保护**：当输入值超出工程值范围时，输出会被钳位到实际值的上下限。

**示例**：

| 表达式 | 含义 | 采集值 32768 → 输出 |
|---|---|---|
| `线性;0;100;0;65535` | 0~65535 映射到 0~100 | 50.0 |
| `线性;-40;120;0;4095` | 0~4095 映射到 -40~120 | 23.0 |
| `线性;0;200;4;20` | 4~20mA 映射到 0~200 | 采集值 12 → 100 |

**典型场景**：
- 模拟量输入（AI）模块的 4-20mA / 0-10V 信号转物理量
- ADC 原始读数转工程单位

### 换算执行流程

```
采集原始值
    │
    ▼
Conversion 为空？
    ├── 是 → 直接类型转换（采集类型 → 输出类型）→ 输出
    └── 否 → ExpressionCalc 表达式换算 → 类型转换 → 输出
```

1. 将采集值转为 `float64`
2. 若 `Conversion` 非空，按表达式计算得到换算后的 `float64` 值
3. 将结果从采集类型转换为目标输出类型（`Value_Type`）

### 注意事项

- 表达式中所有数值参数必须为合法的浮点数字符串（支持负数如 `-5`、小数如 `0.1`）
- 参数数量必须严格匹配：比例模式恰好 3 段，线性模式恰好 5 段，否则返回错误
- 线性模式中 `实际值上限 - 实际值下限` 和 `工程值上限 - 工程值下限` 均不能为 0（除零保护）
- `Conversion` 字段为空字符串 `""` 时跳过换算，仅做类型转换
